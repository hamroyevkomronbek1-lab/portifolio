## ✨ About This Project

This is my personal portfolio website, a fast, lightweight, single-page site built from scratch with **no frameworks and no dependencies**. It shows my selected work, a short bio, and ways to contact me.

**Sections**
- 🏠 **Hero**: bold typographic intro
- 💼 **Selected Work**: project list with hover effects
- 🙋 **About**: who I am and what I do
- 📬 **Contact**: links and email

## 🎯 Technical Highlights

- **Pure HTML & CSS**: no build step, no libraries, loads instantly
- **Responsive layout**: CSS Grid, Flexbox, and fluid typography with `clamp()`
- **Design tokens**: colors and fonts managed with CSS custom properties
- **Accessible by default**: semantic HTML, ARIA labels, visible focus states, `prefers-reduced-motion` support
- **Custom typography**: Bricolage Grotesque + Source Serif 4 via Google Fonts
- **Smooth interactions**: CSS-only animations and hover transitions
- **Deployed on Netlify and GitHub Pages**
